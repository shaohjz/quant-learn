# 策略晋级政策

> QL-014: Paper → 小额 → 放量晋级门槛
> 日期: 2026-07-13

## 核心原则

**不以胜率为唯一目标，核心目标是扣费后期望收益、回撤和破产概率。**

高胜率但平均亏损远大于平均盈利的策略仍应淘汰。

## 晋级流程

```
研究 → Paper模拟 → 小额实盘 → 逐步放量
         ↑              |
         └─ 风险门槛失败 ←┘ (自动降级)
```

## 各阶段门槛

### 数据门槛
- ✅ 所有决策均有 data_hash / config_hash
- ✅ 无未来数据违规
- ✅ 关键行情陈旧率为 0

### 研究门槛
- 至少 3 个不同市场状态
- 建议至少 100 笔相对独立的已平仓交易（不足则标记证据不足）
- OOS 超额收益在多数滚动窗口为正（>50%）
- 2 倍成本压力下净期望仍为正
- 收益不由单一股票或单一月份主导

### Paper门槛
- 建议至少运行 60 个交易日
- 回测/Paper信号一致率 > 90%
- 成交偏差 < 2%
- 拒单率 < 10%
- 最大回撤未突破预设风险预算
- OMS每日对账无未解释差异

### 放量门槛
- 先极小资金
- 按风险额度分级增加，**不按近期盈利倍增**
- 任一风险门槛失败 → 自动降级到 Paper
- Kill switch 随时可用

## 降级规则

| 触发条件 | 动作 |
|----------|------|
| 最大回撤突破风险预算 | 立即降级到 Paper |
| OMS 对账不一致 | 禁止新开仓 + 人工审查 |
| 行情数据陈旧 | 禁止新开仓 |
| 通知系统故障 | 本地 durable queue 缓存 + 告警 |

## 禁止事项

- ❌ 不允许手工跳过 P0 门槛
- ❌ 不按近期盈利倍增资金
- ❌ 不凭 2-6 笔交易放大资金
- ❌ 不在最终 holdout 上反复运行并继续调参

## 代码实现

- `research/promotion_gate.py` — 机器可读晋级规则
- `quant_core/risk.py` — TradingHealthGate (fail-closed)
- `broker/trading_gate.py` — LiveTradingGate (自动交易总闸)
