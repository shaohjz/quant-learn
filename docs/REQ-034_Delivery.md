# REQ-034 交付说明

## 任务信息
- **任务 ID**: REQ-034
- **任务标题**: 支持双账户执行一致性诊断与镜像差异归因
- **优先级**: P1
- **状态**: ✅ 已完成
- **完成时间**: 2026-06-01

## 需求描述
从今日双账户复盘看，sim 已产生 8 只持仓和 9 笔自动买入，而 QMT live 账户仍为空仓且无成交。需要在复盘中自动识别模拟盘与实盘/QMT之间的持仓、成交、现金利用率和策略执行差异，并给出原因分类（未开启实盘、风控拦截、下单失败、同步延迟、账户配置差异等）及下一步处理建议，避免用户误以为策略已在实盘同步执行。

## 实现方案

### 核心模块
`sim/mirror_diagnostics.py` - 双账户一致性诊断器

### 功能清单
1. ✅ 对比 sim_account (模拟盘) 与 QMT live 账户的持仓差异
2. ✅ 对比成交记录差异
3. ✅ 对比现金利用率差异
4. ✅ 检查订单状态异常（被拒绝、超时、部分成交）
5. ✅ 对差异进行原因分类（8 种原因类型）
6. ✅ 给出下一步处理建议
7. ✅ 输出结构化诊断报告（Markdown + JSON）
8. ✅ 集成到每日复盘流程
9. ✅ 支持独立推送诊断报告到企微

### 原因分类
| 原因代码 | 说明 | 处理建议 |
|---------|------|----------|
| `not_started` | 实盘未开启 / QMT 未登录 | 确认 QMT 已登录且策略已启动 |
| `risk_blocked` | 风控拦截 | 检查实盘风控设置 |
| `order_failed` | 下单失败 | 查看 QMT 日志确认原因 |
| `sync_delay` | 同步延迟 | 等待或手动刷新订单状态 |
| `config_mismatch` | 配置差异 | 检查双账户配置一致性 |
| `broker_rejected` | 券商拒绝 | 检查价格是否合规 |
| `timeout` | 订单超时 | 调整价格或重新下单 |
| `partial_fill` | 部分成交 | 检查剩余订单状态 |

## 使用方式

### 1. 命令行直接运行
```bash
# 诊断今天的差异，并打印报告
python sim/mirror_diagnostics.py --print

# 诊断指定日期，保存报告
python sim/mirror_diagnostics.py --date 2026-06-01
```

### 2. 推送诊断报告到企微
```bash
# 推送摘要（默认）
python scripts/push_diagnostics.py

# 推送完整详细报告
python scripts/push_diagnostics.py --detail

# 只生成不推送（dry-run）
python scripts/push_diagnostics.py --dry-run
```

### 3. 集成到每日复盘
在 `scripts/daily_review.py` 中已集成诊断功能，每日自动复盘时会自动运行诊断并将摘要附加到企微推送消息中。
