# REQ-004: 实时刷新动画 + 数据更新提示

## 背景
当前数据30秒自动刷新，但刷新时无任何视觉反馈，用户不知道数据是否最新。价格变化也没有颜色闪动提示。

## 需求描述
1. **价格变化闪动**：价格更新时，上涨短暂闪绿色背景，下跌闪红色背景（0.5秒渐隐）
2. **最后更新时间**：顶部显示"最后更新: 15:30:05"，超过60秒显示黄色警告
3. **刷新按钮动画**：点击刷新时按钮旋转
4. **网络状态指示**：右上角小绿点表示连接正常，红点表示刷新失败
5. **数据对比**：刷新时对比前后数据，变化的字段加粗0.5秒

## 验收标准
1. 价格变动时有0.5秒色块闪动
2. 顶部有实时更新时间
3. 网络异常时有红色提示
4. 动画流畅不卡顿
