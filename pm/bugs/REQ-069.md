# REQ-069: sim_daily_nav 日表 07-20 learn(acc1) 记录未反映当日建仓，market_value=0 失真

## 描述

复盘发现 sim_daily_nav 表中 account_id=1 (learn) 的 2026-07-20 记录：
  total_value=100000, cash=100000, market_value=0, daily_return=0, cumulative_return=0

但实际 sim_positions(acc1) 当日有 3 笔建仓（000600/000725/300146），市值 28194，且 sim_account.acc1.total_value=100114.99、cash=71920.99 与持仓表一致。

即：NAV 日表在收盘后未更新当日持仓快照，导致每日收益、累计收益核算失真。
此问题与已 verified 的 REQ-066（07-14/07-15 learn 账户 NAV 记录缺失）属同类复发，说明日终 NAV 写入链路对新建仓日的覆盖不稳定。

修复建议：
1. 复盘 sim_daily_nav 写入逻辑，确认收盘快照是否覆盖当日有建仓但此前无持仓的账户；
2. 增加 NAV 与 sim_account/sim_positions 的一致性校验（market_value 应等于 sum(positions.market_value)）；
3. 对空仓->建仓过渡日做专项回归测试。

## 修复备注

复盘确认：07-21 复盘时 acc1(learn) sim_daily_nav 仍无当日记录，最新仅 07-20 空仓快照(market_value=0)。今日实际建仓京东方A/豫能控股/网宿科技3只共市值约28571，acc1总值已达101628.87，NAV表完全未反映，daily_return/cumulative_return 无法核算。P0 仍未闭环。
2026-07-28: sim_executor BUY/SELL only adjust cash then total=cash+Σmv; daily_close syncs account total.
