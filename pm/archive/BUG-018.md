# 每日复盘报告缺失：2026-05-27 未生成

## 描述

2026-05-27（周三）的每日复盘报告未生成，但 docs/reviews/ 目录下只有 2026-05-26 和 2026-05-18 两个文件。需要排查自动化任务是否失败，或增加缺失报告自动告警机制（参考 REQ-047）。

## 根因

Report generator and missing-review monitor used different directories: output/reviews vs docs/reviews.

## 修复备注

BUG-018 fixed by PM-Agent-dev-2. Root cause: active daily_review.py writes generated reports to output/reviews, while review_missing_check monitored docs/reviews by default, so 2026-05-27 was falsely treated as missing even though output/reviews/2026-05-27.md existed. Fix: review_missing_check now defaults to output/reviews with docs/reviews as legacy fallback, adds compatible check_review/CLI args, improves alert schema compatibility, and validates missing/empty/incomplete behavior. Validation: python -m pytest tests\test_req037_review_missing_check.py tests\test_req047_review_missing_check.py -q => 9 passed; python -m py_compile scripts\review_missing_check.py; CLI dry-run for 2026-05-27 returns ok against output/reviews. Commit 05d8d920.
