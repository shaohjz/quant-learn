# REQ-092: 买入前估值分析 — 结合PE/PB/估值分位过滤信号

## 描述

## 需求描述
当前系统买入信号（trend_break_buy / buy_zone / buy_strong）仅基于技术面（价格突破、成交量、均线等），缺乏基本面估值过滤。

## 具体需求
1. **估值数据接入**：获取 A 股个股的 PE(TTM)、PB、行业估值分位数据
2. **估值过滤规则**：
   - 买入信号触发时，先检查该股票估值是否合理（如 PE < 行业均值 * 1.5、PB < 3 等）
   - 估值过高（如 PE > 100 或处于历史 90% 分位以上）直接过滤，不执行买入
3. **每日扫描过滤**：watchlist 生成时增加估值条件，只保留低估值股票
4. **估值信号写入**：将估值分析结果写入 strategy_shadow_signals 表（strategy_id='valuation_filter'）
5. **与现有信号结合**：技术信号 + 估值过滤双重确认后才执行买入

## 优先级
P1 - 重要但不紧急（当前模拟盘资金少，影响有限，但长期必须）

## 参考
- a-stock-data skill 已有财务数据接口（mootdx 财务/F10、东财、新浪三表）
- 可复用 a-stock-data 的估值数据获取能力
