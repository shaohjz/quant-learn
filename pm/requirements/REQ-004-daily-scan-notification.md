# REQ-004: 每日扫描结果推送通知

## 基本信息
- **需求 ID**: REQ-004
- **标题**: 每日扫描结果推送通知
- **状态**: deployed
- **优先级**: P0
- **创建时间**: 2026-06-10 01:20
- **创建人**: PM Agent (quant-finance-manager)
- **指派给**: 研发 Agent

## 背景
用户不清楚每天系统有没有扫描股票、扫描了多少只、选出了哪些观察标的、哪些可能交易。需要每天在企微群推送扫描结果通知。

## 目标
每天定时向用户企微推送扫描结果，让用户了解系统运行状态。

## 详细需求
1. **扫描概览**：
   - 今日扫描了多少只股票
   - 扫描时间范围（盘前/盘中/盘后）
   - 数据源是否正常

2. **观察列表**：
   - 选出了哪些股票进入观察列表
   - 入选理由（技术面/基本面/其他）
   - 观察列表文件路径

3. **交易信号**：
   - 哪些股票今天可能会交易（买入/卖出信号）
   - 触发条件（阈值突破/均线破位/其他）
   - 预计交易时间

4. **推送方式**：
   - 企微消息推送
   - 推送时间：每日 09:35（开盘后）、14:30（尾盘前）
   - 推送格式：简洁卡片，一目了然

## 数据来源
- `scripts/daily_advisor.py` 扫描结果
- `scripts/intraday_scanner.py` 盘中扫描结果
- `scripts/portfolio_alert.py` 持仓告警
- `data/sim_live_mirror.db` 实盘数据

## 验收标准
1. ✅ 每日 09:35 推送早盘扫描结果（扫描股票数、观察列表、交易信号）
2. ✅ 每日 14:30 推送尾盘扫描结果（当日交易情况、持仓变化）
3. ✅ 推送内容包含：扫描股票数、观察列表、交易信号、数据源状态
4. ✅ 数据源异常时推送告警

## 优先级理由
- P0：用户无法感知系统是否正常运行，影响信任
- 需要让用户每天知道系统在干活
