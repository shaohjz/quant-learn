## 二、BUG-012 验证详情

### 2.1 缺陷描述

跨日复盘 `docs/reviews/2026-05-19.md` → `docs/reviews/2026-05-26.md`，同一 sim 25000 账户初始资金由 25,000 跳变为 100,000，导致总资产、现金和浮动收益率口径跨日不可比，误导风控和复盘判断。

### 2.2 修复方案审查（commit 3a4b639）

`scripts/daily_review_vnpy.py`：
- 新增 `_parse_money` / `_extract_report_initial_cash`：解析历史复盘 Markdown 概览表中的初始资金。
- 新增 `_previous_initial_cash_mismatch`：扫描 `docs/reviews/*.md`，找出最近一份与当前 initial_cash 不一致的报告。
- 新增 `detect_capital_basis_changes`：对 `sim 25000` 与 `QMT mini 90072426` 两个账户执行检测。
- `render_markdown` 输出：
  - 概览表「初始资金」单元加 ⚠️ 标记，「浮动收益率」加（当前口径）后缀；
  - 在概览表后追加「⚠️ 资金口径变更提示」段落，明确指出"跨日收益率/总资产对比已暂停解释，请仅按当前资金口径阅读本日报告"。

### 2.3 自动化测试

`tests/test_daily_review.py::test_render_markdown_warns_on_initial_cash_jump`：构造 25,000 → 100,000 跳变场景，断言：
- `detect_capital_basis_changes` 返回正确的 account / current / previous / previous_day 字段；
- 渲染出的 Markdown 同时包含 "资金口径变更提示"、"25,000"、"100,000"、"跨日收益率/总资产对比已暂停解释"。
