# 量化通知/盘中盯盘 cron 去大模型化 — agentTurn → systemEvent

## 描述

目标：把 12 个 agentTurn cron 改为 systemEvent，让主 session 直接调脚本 → POST 企微 Webhook，不再消耗 token。

改造清单（12 个 cron）：
1. auction-9:24 集合竞价快报
2. morning-brief-9:25 多策略简报
3. auction-9:31 开盘快报
4. post-15:05 收盘复盘
5. daily-review 15:10
6. intraday-watch (上午 9:35/55)
7. intraday-watch-am (上午 10:15/35/55)
8. intraday-watch-noon (11:15)
9. stock-alert-light (14:00/20/40/55)
10. intraday-watch-pm (下午 13:05/25/45)
11. intraday-watch-pm2 (下午 14:05/25/45/55)
12. intraday-watch-pm (下午 15:05)

改造步骤（每个 cron 一样）：
- sessionTarget 改为 'main'
- payload.kind 改为 'systemEvent'
- payload.text 改为脚本执行命令
- 删除 payload.thinking / timeoutSeconds / toolsAllow
- delivery.mode 保持 'announce'

验收标准：
- [ ] 所有 12 个 cron payload.kind = 'systemEvent'
- [ ] 盘中触发时，企微群能收到 🔔 开头的消息
- [ ] Token 消耗降为 0
