# REQ-002: 收益率曲线图

## 背景
用户最关心的核心指标是"我赚了多少钱"。目前仪表盘只有一个总收益率数字，无法看到收益随时间的变化趋势，无法判断是稳步上升还是剧烈波动。

## 需求描述
在实盘和模拟盘 Tab 顶部增加**收益率曲线图**：
1. 使用 ECharts（CDN引入）绘制折线图
2. X轴：日期（近30天）
3. Y轴：累计收益率(%)
4. 两条线：实盘收益 + 沪深300基准
5. 鼠标悬浮显示具体日期和数值
6. 支持缩放和拖拽

## 数据来源
- 新建 `daily_snapshot` 表：每日收盘后记录当日总资产、总市值、现金
- 后端 API：`/api/equity_curve?days=30` 返回每日资产数据
- 基准数据：用 BaoStock 拉沪深300指数

## 验收标准
1. 折线图正确显示近30天收益率走势
2. 鼠标悬浮有 tooltip
3. 图表自适应宽度
4. 移动端可横屏查看
5. 无数据时显示"暂无数据，明天开始积累"

### 技术实现
- ECharts CDN: `https://cdn.jsdelivr.net/npm/echarts@5/dist/echarts.min.js`
- 配色：收益线 #1a73e8（蓝色），基准线 #9ca3af（灰色）
- 空数据提示："⚠️ 暂无数据，明天开始积累"
- 响应式：自动适应容器宽度
- 数据源：`daily_snapshot` 表（账户类型 'sim'）
