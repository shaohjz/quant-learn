# buy_zone 拦截止损缺口未补 + 信号文案串价今日(07-10)继续误导建仓

## 描述

根因: TASK-20260709-2004-001 研发验收退回后仍误标 fixed。
1) buy_zone 的 MA 偏差>5% 仅有告警(_check_buy_zone_ma_deviation)未实现拦截，而 buy_strong 已拦截，缺口仍在。
2) 告警函数用正则从 rule.message 提取'跌至 X'算偏差，但 fix_buyzone_signal_text.py 已改写历史文案为'跌至 44.17(实际成交价)，昨日 MA10=57.33'，正则取到成交价偏差恒为0%，且未来新格式'BuyZone 阈值 X（MA10=Y）'无'跌至'字样，正则直接跳过——历史/未来均不告警。
3) 今日 07-10 09:30 三笔 BUY 信号参考价/MA10 全为错误串价(广西能源5.31/上海电力18.11/天赐材料57.33，实际建仓3.82/13.82/43.94)，其中天赐材料(002709)基于错误信号建仓后跌至40.52，跌破移动止损40.64，浮亏-8.02%。
处置: 补全 buy_zone 偏差>5%拦截逻辑(对齐 buy_strong 的 _check_ma20_deviation return NO_ACTION)，修正告警函数直接从阈值字段取 MA10 而非正则 message；信号 signal_reason 中的'昨日 MA10'错误展示需根除。
