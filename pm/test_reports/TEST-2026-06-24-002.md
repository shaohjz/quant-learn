## 发现问题

### 问题 1（P1 — 修复不完整）：`generate_report()` 中大量 emoji 未替换

**详细描述**：
原 Bug 修复只替换了 3 处 `print()` 语句中的 emoji，但 `generate_report()` 函数（生成推送到企微的 Markdown 报告）中仍有约 **10+ 处** Unicode 表情符号未处理：

1. ⚠️（U+26A0）— 止损预警、阈值异常标题
2. 🎉（U+1F389）— 止盈提示
3. 🔴（U+1F534）— 移动止损、卖出信号
4. 🟢（U+1F7E2）— 买入信号
5. ⚪（U+26AA）— 持仓信号
6. ✅（U+2705）— 无预警提示
7. 🚨（U+1F6A8）— 风险预警标题
8. 📊（U+1F4CA）— 策略信号标题

**影响**：
- 当 `print(report)` 在 GBK 终端执行时，仍可能触发 `UnicodeEncodeError`
- 企微 Markdown 推送内容含 emoji，在某些客户端可能显示异常

**建议修复方案**：
将 `generate_report()` 中所有 emoji 统一替换为纯文本标记：
- ⚠️ → `[警告]`
- 🎉 → `[止盈]`
- 🔴 → `[卖出]`
- 🟢 → `[买入]`
- ⚪ → `[持仓]`
- ✅ → `[成功]`
- 🚨 → `【风险预警】`
- 📊 → `【策略信号】`
