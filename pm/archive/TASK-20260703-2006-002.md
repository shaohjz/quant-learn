# 工业富联买入即止损（信号滑点/延迟问题）

## 描述

2026-07-02 10:00以65.85买入工业富联(601138)，当日14:30以64.51止损卖出，单笔亏损约2.05%。买入信号为buy_strong（回调至66.62入场区），但实际买入价65.85已明显低于信号触发价，说明从信号生成到实际下单之间存在价格滑点。类似问题在多个标的出现，建议：(1)买入前重新校验当前价是否仍在信号有效区间内；(2)加入买入前滑点检查（当前价vs信号触发价偏差>1%则放弃)； (3)考虑盘中信号延迟，将信号有效期缩短至5分钟内。
