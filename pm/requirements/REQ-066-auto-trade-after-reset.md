# REQ-066: 清仓重置后策略全自动运行 — 信号实时执行

## 基本信息
- **需求 ID**: REQ-066
- **标题**: 清仓重置后策略全自动运行 — 信号实时执行
- **状态**: deployed
- **优先级**: P0
- **创建时间**: 2026-06-24
- **创建人**: PM Agent
- **指派给**: 研发经理

## 背景
账户已清仓重置到10万初始资金，从明天开始策略需要全自动选股、买入、卖出。当前最大的问题是**信号触发后执行延迟数周**，导致买入成本远高于信号触发价。

## 需求描述

### 1. 信号实时执行（P0）
- 信号触发后，**不再等待复盘/修复脚本**，应在盘中或盘后第一时间自动执行
- 梳理当前信号链路：`threshold_alert` → `morning_scanner` / `intraday_scanner` → 下单执行
- 确保 `auto_trade` 配置为 `true` 时，信号触发立即下单
- 检查 `sim/engine.py` 或 `sim/executor.py` 中是否有延迟执行的逻辑，移除或缩短

### 2. 止盈自动执行（P0）
- 当前 `take_profit` 信号 armed 后从未自动卖出
- 需要确保止盈信号触发后自动生成卖出订单
- 建议：浮盈 ≥30% 时自动卖出 50%，≥50% 时卖出剩余

### 3. 止损阈值评审（P1）
- 当前止损在 -10%~-20% 触发，但很多止损后股票反弹
- 建议评估是否引入时间维度止损（持有X天仍亏损才止损）

### 4. 仓位管理优化（P1）
- 当前单只仓位占比过低（3-5%），赚钱赚不多
- 建议单只仓位上限 15-20%，持仓 5-8 只

## 验收标准
1. ✅ 信号触发后 1 小时内自动执行（非交易日除外）
2. ✅ 止盈信号 armed 后自动卖出
3. ✅ 新账户从 10 万开始，无历史持仓干扰
4. ✅ 每日复盘报告显示正确的累计收益率
