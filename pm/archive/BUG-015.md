# 非交易时段 cron 任务空跑浪费资源（runner + portfolio_alert 每10分钟无效执行）

## 描述

runner.log 和 portfolio_alert.log 显示：非交易时段（15:30之后到次日9:15之前）每10分钟触发一次任务，全部返回'非交易时段，退出'。全天约144个间隔，非交易时段约占16小时=96次无效执行/每个cron。需改为：1) 交易时段才注册/唤醒 cron；2) 或在任务入口处加 is_trading_time() 早起检跳，非交易直接退出且不写日志；3) 或用 Windows 计划任务只在交易时段调度。
