# trailing stop 止损价未上移，全部等于/低于成本价

## 描述

全部持仓 trailing_stop_price 均 ≤ avg_cost：广西能源 3.90(=成本) / 华能蒙电 4.41(<成本4.75) / 中国电信 5.64(=成本) / 大唐发电 5.24(<成本5.70) / 圆通速递 15.97(<成本17.36)。移动止损逻辑疑似未根据 highest_price 上移止损价，导致保护位停留在建仓成本甚至更低，失去 trailing stop 意义，且部分标的已跌破止损价却未触发平仓信号。需检查 trailing stop 更新逻辑与触发判定。

## 根因

待查：trailing stop 价格更新流程未执行或阈值计算错误

## 修复备注

修复：1) sim/db.py新增get_default_trailing_stop()建仓默认-5%止损；2) calc_trailing_stop_price当无现有止损时自动回退到默认-5%止损；3) engine.py建仓用get_default_trailing_stop替代旧hard 92%止损；4) 运行backfill_trailing_stop.py补全3个现有持仓的止损价（圆通16.49、华能蒙电4.51、大唐发电5.42）
