# BUG-001: REQ-003统计API返回JSON不完整/异常

## 严重级别
S1 严重

## 状态
open

## 关联需求
REQ-003: 持仓饼图 + 统计页增强

## 发现来源
研发子 agent 在实现/自测 REQ-003 时发现：`/api/stats` 返回 JSON 不完整或异常，导致统计页增强无法完成验证。

## 现象
- 调用统计相关 API 时返回内容不完整，疑似后端异常或 JSON 序列化/聚合逻辑问题
- REQ-003 开发中断，未能进入 testing

## 影响
- 阻塞 REQ-003 交付
- 统计页可能显示异常或加载失败

## 复现步骤
1. 启动 Web 服务：`.venv\\Scripts\\python.exe web/app.py`
2. 调用：`Invoke-WebRequest http://127.0.0.1:8080/api/stats`
3. 检查返回 JSON 是否完整，是否包含增强字段：`win_rate`, `avg_hold_days`, `month_trades` 等

## 期望结果
- `/api/stats` 返回合法 JSON
- 至少包含：`total_trades`, `week_trades`, `month_trades`, `win_rate`, `avg_hold_days`
- 前端统计页可正常渲染

## 处理建议
1. 检查 `web/app.py` 中 `api_stats()` 聚合 SQL
2. 对空数据/NULL 做兜底
3. API 返回前用 `jsonify`，避免不可序列化对象
4. 加一个本地验证脚本或 curl 测试

## 回归标准
- `/api/stats` HTTP 200
- 返回 JSON 可解析
- 统计页无 JS 报错
- REQ-003 状态可进入 `testing`
