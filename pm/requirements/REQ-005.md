# REQ-005: 观察列表K线缩略图

## 背景
观察列表目前只有价格数字，无法直观判断股票走势形态。对于判断"是否到了买入区间"，一张小K线图比数字有用10倍。

## 需求描述
在观察列表每只股票卡片右侧，增加一个迷你K线图（sparkline 风格）：
1. 展示近20日K线（用细线+阴阳柱）
2. 标注 buy_zone 和 buy_strong 触发线（水平虚线）
3. 宽度约120px，高度40px
4. 无需交互，纯展示

## 数据来源
- 新增 API：`/api/kline/<code>?days=20` 返回近20日OHLC数据
- 数据源：BaoStock 历史K线（缓存到本地，每日更新一次）

## 验收标准
1. 每只观察股右侧有迷你K线图
2. buy_zone/buy_strong 线明确可见
3. 加载时有占位skeleton
4. K线数据每日自动更新
