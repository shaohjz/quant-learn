# 支持将每日复盘思考（手工填写项）自动写入数据库或持久化保存

## 描述

当前 docs/reviews/ 的复盘报告中留有手工填写的思考问题，但这些手写内容在系统重新生成或没有外部收集机制时会被忽略，建议增加一个脚本或机制，将 Markdown 中的手写思考同步到 sqlite 数据库中进行持久化分析。
