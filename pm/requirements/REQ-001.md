# REQ-001: UI浅色主题优化

## 背景
原暗色主题对比度不足，部分文字（灰色 #8b949e 在 #0d1117 背景上）辨识度差，用户反馈"黑黑的看不清"。

## 需求描述
将仪表盘从暗色主题改为浅色主题，提升可读性：
1. 背景改为浅色（#f5f7fa）
2. 卡片用白色底+阴影
3. 文字用深色（#1f2937）
4. 强调色保持蓝色系（#1a73e8）
5. 涨跌色保持红绿

## 验收标准
1. 所有文字在浅色背景上对比度≥4.5:1 (WCAG AA)
2. 卡片有轻微阴影区分层次
3. 筛选按钮 active 态清晰可辨
4. 移动端适配正常
