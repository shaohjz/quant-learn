# buy_zone 信号参考价/MA10 价系统性错乱（002709/600021/001896 串价）

## 描述

【现象】2026-07-09 模拟盘 buy_zone 建仓信号中，"跌至 X 接近 MA10(X)" 引用的参考价与真实成交价严重偏离：
- 002709 天赐材料：信号引用 57.33，实际成交 44.17，偏离 -13.16 元（-23%）
- 600021 上海电力：信号引用 18.11，实际成交 13.78，偏离 -4.33 元
- 001896 豫能控股：信号引用 16.12，实际成交 13.99，偏离 -2.13 元
【影响】与已 verified 的 REQ-060（西部材料信号与MA偏离）同源但范围更广，说明信号生成层对参考价/MA 价格的映射存在系统性错乱（疑似跨标的串价或使用了上一交易日/其他标的的快照价）。本日3笔建仓全部当日浮亏（002709 -5.21%、001896 -1.91%、600021 -0.36%），"建仓即浮亏"模式重现，与 TASK-20260705-0215-004 / TASK-20260707-2009-000600（建投能源买入即止损）一致。
【诉求】① 定位 buy_zone 信号中 MA10/参考价的取值来源，校验是否串标的；② 在信号生成时增加"引用价 vs 成交价偏差>5%"的告警与拦截；③ 回归测试已 verified 的 REQ-060 修复是否覆盖本类场景。

## 修复备注

【09:00 研发验收退回】修复不完整且存在逻辑矛盾，未达验收标准：
1) 诉求②'偏差>5%告警与拦截'：代码(_check_buy_zone_ma_deviation)仅做了告警，明确'不拦截执行'；而同源的 buy_strong 已实现拦截(_check_ma20_deviation return NO_ACTION)，buy_zone 拦截缺口仍在。
2) 告警逻辑实际失效：该函数从 rule.message 正则'跌至 X'提取参考价算偏差。但 fix_buyzone_signal_text.py 已把历史文案改写为'跌至 44.17（实际成交价），昨日 MA10=57.33'——正则提取到的是成交价，偏差恒为0%，永不告警；且未来新信号 message 格式为'BuyZone 阈值 X（MA10=Y）'，无'跌至'字样，正则直接跳过。即历史/未来均不触发告警。
3) 根因定性偏差：57.33/18.11/16.12 实为各票自身 07-08 MA10（非跨标的串价），问题本质是'昨日MA10误展示造成视觉混淆'，但修复未纠正 signal_reason 中保留的错误'昨日 MA10'展示，仅加'实际成交价'前缀，未根除误导。
4) 诉求③ REQ-060 回归：REQ-060 修复仅覆盖 buy_strong，未覆盖 buy_zone，缺口确认未补。
结论：需补全 buy_zone 偏差>5%的拦截逻辑，并修正告警函数对 message 格式的解析（应直接从阈值字段取 MA10，而非正则 message）。
