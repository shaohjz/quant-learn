## 背景
复盘报告显示 account_id=1 累计收益率为 -78.13%，但实际亏损远小于此值。

## 根因分析
1. **建仓时 initial_cash = 43,014.50**（用户真实持仓快照时的实际本金）
2. **2026-06-19 修正 initial_cash → 100,000.00**（目标初始资金）
3. **但 total_value 从未修正**，一直停留在基于 43,014.50 时的资产水平
4. 导致 `cumulative_return = (21866.55 - 100000) / 100000 = -78.13%`（虚假亏损）

## 修复方案
1. 计算差额：100,000 - 43,014.50 = 56,985.50
2. 将差额注入 `sim_account.cash` 和 `sim_account.total_value`
3. 重新计算所有 `sim_daily_nav` 记录的 `cumulative_return`
4. 记录账户事件到 `sim_account_events`

## 修复结果
| 指标 | 修复前 | 修复后 |
|------|--------|--------|
| total_value | 21,881.55 | 78,867.05 |
| cash | 5,470.55 | 62,456.05 |
| cumulative_return | -78.13% | -21.13% |
| 持仓市值 | 16,396.00 | 16,396.00（不变） |
