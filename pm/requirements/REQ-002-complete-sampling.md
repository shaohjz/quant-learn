# REQ-002: 完善盘中采样覆盖

## 基本信息
- **需求 ID**: REQ-002
- **标题**: 完善盘中采样覆盖
- **状态**: deployed
- **优先级**: P1
- **创建时间**: 2026-06-09 18:11
- **创建人**: PM Agent (quant-finance-manager)
- **指派给**: 研发 Agent

## 背景
当前盘中采样仅覆盖 13:00-14:50，缺失上午盘（09:30-11:30）和收盘阶段（14:50-15:00），无法完整监控盘中持仓变化。

## 目标
确保盘中采样覆盖完整交易时段，捕获所有关键时点。

## 详细需求
1. **完整覆盖交易时段**：
   - 上午盘：09:30-11:30
   - 下午盘：13:00-15:00
   - 按 5-10 分钟频率采样

2. **关键时点覆盖**：
   - 开盘：09:30
   - 收盘：15:00
   - 午间收盘：11:30, 13:00

3. **监控和告警**：
   - 采样失败告警
   - 覆盖不完整告警（如：上午采样为 0）
   - 复盘报告在 15:05 后生成

## 验收标准
1. ✅ 交易时段内按 5-10 分钟频率采样
2. ✅ 覆盖开盘（09:30）、收盘（15:00）关键时点
3. ✅ 采样失败或覆盖不完整时告警
4. ✅ 复盘报告在 15:05 后生成
5. ✅ `portfolio_alert_runner.bat` 或 cron 配置正确

## 实现记录

### 1. Windows任务计划程序配置
- 任务名称：`QuantLearn_PortfolioAlert`
- 开始时间：09:30
- 重复间隔：每10分钟
- 持续时间：6小时（到15:30）
- 运行权限：最高权限

### 2. 采样覆盖监控
- 创建 `scripts/check_sampling_coverage.py`
- 检查上午盘和下午盘采样覆盖率
- 覆盖率 < 80% 时输出告警

### 3. 集成到 portfolio_alert.py
- 在收盘后（15:00-15:30）自动检查覆盖率
- 覆盖率不足时通过 webhook 推送告警到企微群

### 4. 验证复盘报告调度
- `QuantLearn_DailyReview` 任务在 15:30 运行
- 满足"复盘报告在 15:05 后生成"的需求
