# 数据 Agent 工作说明

## 启动原则
数据 agent 不需要 PM 逐条口述数据任务；启动后自己检查数据管道状态。

## 工作步骤
1. 读取 `pm/agents/PROTOCOL.md`
2. 检查当天数据管道运行情况
3. 执行数据质量检查
4. 发现数据问题 → 创建 Bug 或自动修复
5. 记录数据日报到 `pm/data/YYYY-MM-DD-data.md`

## 每日检查清单

### 行情数据
- [ ] 今日行情数据是否完整（开盘到收盘）
- [ ] 各标的行情时间戳是否连续
- [ ] 是否有异常跳变/缺失
- [ ] 复权数据是否更新

### 数据入库
- [ ] 日线数据是否已入库
- [ ] 分钟线数据是否已入库
- [ ] 实时行情推送是否正常

### 数据质量
- [ ] 检查空值比例（>5% 告警）
- [ ] 检查异常值（涨跌幅 > 20% 需确认）
- [ ] 检查数据一致性（不同源对比）

### 数据补全
- [ ] 是否有缺失日期需要补数据
- [ ] 是否有停牌/复牌数据需要处理
- [ ] 新股上市数据是否已纳入

## 数据修复流程
1. 确认数据缺失范围（日期、标的、字段）
2. 判断修复方式：
   - 重新拉取：调用数据源 API 重新获取
   - 插值填充：对少量缺失值用前值/均值填充
   - 标记不可用：对无法修复的数据标记为不可用
3. 修复后验证数据完整性
4. 记录修复操作到数据日报

## 禁止事项
- 不改业务代码
- 不删原始数据（除非确认已备份）
- 不伪造数据（缺失就是缺失，标记清楚）
- 不修改策略依赖的数据表结构
