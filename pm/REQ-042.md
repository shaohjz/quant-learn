## 动机
当前所有量化通知（盘前/开盘/收盘/盘中盯盘）都依赖 cron → agentTurn → 大模型推理 → 发消息。
每次任务都消耗大量 token，而且有思考延迟。

## 目标
纯代码脚本（Python）直接跑逻辑 → 结果 JSON → 调用企微机器人 Webhook → 推送到群/个人。

不依赖任何大模型推理。

## 方案概要

### 1. 企微自定义机器人 Webhook
- 在企微群里添加一个「自定义机器人」，拿到 Webhook URL
- 脚本用 requests.post(webhook_url, json={msgtype, markdown/text, ...}) 推送
- 支持 markdown 格式（标题、加粗、代码块）

### 2. 改造对象
| 现有 cron | 改造后 |
|---|---|
| auction-9:24 集合竞价快报 | Python 脚本直接跑 → POST Webhook |
| morning-brief-9:25 多策略简报 | 同上 |
| auction-9:31 开盘快报 | 同上 |
| post-15:05 收盘复盘 | 同上 |
| daily-review 15:10 | 同上 |
| intraday-watch（盘中盯盘） | 同上 |

### 3. 执行方式
cron 从 agentTurn 改为 systemEvent + 本地脚本：
option A: cron → exec python script.py → script 内 POST webhook
option B: cron → 直接 curl/webhook（更简单）

### 4. 消息格式
企微机器人支持 markdown：
```json
{
  "msgtype": "markdown",
  "markdown": {
    "content": "## 🔔 阈值触发\n**中国电信** 跌破 ¥6.20"
  }
}
```

## 收益
- 💰 token 消耗降为 0（这些任务不再调大模型）
- ⚡ 延迟更低（省去大模型推理时间）
- 🔧 更可控（纯代码逻辑，不会 LLM 幻觉）

### 📝 使用说明
1. **配置 Webhook URL**：
   ```yaml
   # config.yaml
   notifier:
     enabled: true
     wecom_webhook: "https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=YOUR_KEY"
   ```

2. **测试脚本**：
   ```bash
   # 测试企微通知
   python scripts/wecom_notifier.py --type text --content "测试消息"
   
   # 测试集合竞价快报（需要先有数据文件）
   python scripts/notify_auction.py
   
   # 测试收盘复盘通知（需要先有复盘报告）
   python scripts/notify_daily_review.py
   ```

3. **配置 cron**（示例）：
   ```json
   {
     "name": "auction-9:24",
     "schedule": {"kind": "cron", "expr": "24 9 * * 1-5"},
     "payload": {
       "kind": "systemEvent",
       "text": "python scripts/notify_auction.py"
     }
   }
   ```
