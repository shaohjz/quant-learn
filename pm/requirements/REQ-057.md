# 盘中14信号executed但0笔买入成交：信号-执行链路断裂复发

## 描述

2026-06-02 threshold_state 记录14个buy_strong/buy_zone信号状态为executed（莲花控股/天赐材料/西部材料/中国电信/大元泵业等），但sim_trades当日0笔BUY成交，仅2笔SELL（天通28.28/华软5.57，且signal_reason为空）。REQ-048/BUG-017同类复发：threshold_state标记executed与实际下单解耦，复盘无法追溯执行。需求：1)executed必须由真实成交回写，不允许仅信号触发即置executed；2)复盘自动比对executed信号vs当日成交，缺口>0告警；3)修复account_id=1净值口径异常(initial_cash=20万但total_value仅2.25万，cumulative_return=-88.7%)。

## 根因

sim_executor.execute_trade 在 NO_ACTION/DEFER/重复买入风控/日内预算风控 等分支返回 success=True 且 trade=None（仅提醒、不写 sim_trades）；threshold_strategy._exec_via_sim 用 result['success'] 作为成交标志，导致买入信号被误标 threshold_state.status='executed' 却无对应成交——信号-执行链路断裂（BUG-017/REQ-048 同类复发）。另：account_id=1 的 initial_cash 误填 200000（实际资金流水反解本金≈25000，DB 现金从未体现充值），致 cumulative_return 失真 -88.7%。

## 修复备注

2026-07-28: same as REQ-048; armed path residual closed.
