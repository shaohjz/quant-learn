# 现有持仓止损自动触发：严重浮亏个股自动卖出机制

## 描述

当前 REQ-039（智能止损P0）已 done，但 2026-05-26 复盘显示 603757 大元泵业浮亏-9.87% 并未触发止损卖出。熔断机制（REQ-028）只阻止新增买入，不处理现有持仓止损。需落地：1) 持仓浮亏超过阈值（如-7%）自动触发市价/限价卖出；2) 支持分批止损（先卖50%，观察后再卖剩余）；3) 止损触发前推送企微确认通知（防止误触）；4) 在复盘报告中标注已止损持仓。
