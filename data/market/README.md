# data/market/ 目录

## 用途
此目录用于存储行情数据相关文件，包括：
- 实时行情缓存
- 市场数据存储
- 数据源临时文件

## 数据来源
行情数据主要通过以下脚本获取：
- `data/fetch_data.py` - 日线数据获取
- `scripts/data_source_manager.py` - 多数据源管理

## 目录结构
```
data/market/
├── README.md          # 本文件
├── *.csv             # 行情数据缓存（可选）
└── market.db         # 行情数据库（可选）
```

## 维护
- 此目录由系统自动创建（如果不存在）
- 可以安全删除（会重新创建）
- 建议定期清理旧数据文件
