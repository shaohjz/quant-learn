## 四、添加新定时任务

### 格式模板

```json
{
  "name": "任务名称",
  "schedule": {
    "kind": "cron",
    "expr": "分 时 日 月 周",
    "tz": "Asia/Shanghai",
    "staggerMs": 300000
  },
  "sessionTarget": "isolated",
  "payload": {
    "kind": "agentTurn",
    "message": "任务提示词...",
    "model": "gongfeng/deepseek-v4-pro",
    "timeoutSeconds": 0
  },
  "delivery": {
    "mode": "announce",
    "channel": "wecom",
    "to": "jizhouhu"
  }
}
```

### 注意事项
- 所有 cron 任务使用 `sessionTarget: "isolated"`（隔离会话）
- 推送目标固定为 `channel: wecom, to: jizhouhu`
- 工作日任务使用 `1-5`（周一到周五）
- 加 `staggerMs: 300000`（5分钟随机偏移，避免同时触发）
- 不改的大需求：REQ-011(vnpy)、REQ-043(去大模型化)、REQ-019(QMT状态流)
