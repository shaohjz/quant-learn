# REQ-007: 暗色/浅色主题切换

## 背景
已改为浅色主题，但部分用户偏好暗色（尤其夜间看盘）。支持主题切换是基础体验需求。

## 需求描述
1. 右上角增加🌙/☀️图标按钮，点击切换主题
2. 使用 CSS 变量实现（已有 :root 变量）
3. 用 localStorage 记住用户选择
4. 暗色主题用之前的配色（#0d1117 背景 + #c9d1d9 文字）
5. 切换时有 0.3s 过渡动画

## 验收标准
1. 点击按钮可切换暗色/浅色
2. 刷新页面保持上次选择
3. 过渡动画流畅
4. 两种主题下文字对比度都达标

## 优先级
P3
