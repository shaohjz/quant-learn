# REQ-061: sim_daily_nav 中 account_id=1 的 daily_return 持续为 NULL

## 描述

sim_daily_nav 表中 account_id=1 的 daily_return 字段在 2026-06-09 和 2026-06-10 均为 NULL，导致无法正确计算当日收益率。需要检查 nav 计算脚本（db_stats.py 或 daily_review 相关脚本）中 daily_return 的计算逻辑，确保每次写入时正确计算 (total_value_today - total_value_yesterday) / total_value_yesterday。
