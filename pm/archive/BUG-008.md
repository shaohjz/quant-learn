# 部分信号文本在成交记录中被截断

## 描述

在双账户复盘报告（2026-05-26）中，sim 账户的自动买入成交记录，其信号列的文本被截断，例如 天赐材料跌至 、万华化学，未完整展示具体的触发价格、阈值或更完整的策略信息，影响历史复盘回溯。需要排查 live_mirror 中存储信号文本长度限制或生成复盘 markdown 时的截断逻辑。
