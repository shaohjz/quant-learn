# 智能止损 P0：量价共振 + 收盘确认

## 描述

现行机械止损（last <= entry*0.92）粗暴，容易在插针/反包日被甲。

改造为三档判定：
1) soft_stop：跌破止损价但量能未放大，软预警、不自动卖
2) confirmed_stop：跌破 + 量比 >= 1.5（放量下跌=主力出货）→ SELL_HALF
3) hard_stop：跌破 stop*0.95（再跌 5%）→ SELL_ALL不留情

增加收盘确认：盘中只预警，14:50 后才执行（避盘中插针）。

涉及文件：
- sim_executor.py：加 _check_stop_loss_confirmed，返回 软/确/硬 三档动作
- portfolio_alert.py：区分 soft/confirmed/hard 三个 level，带量能说明
- daily_advisor.py：预警件带量能上下文（今日量比 / 是否近收盘）
